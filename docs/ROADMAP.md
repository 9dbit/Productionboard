# Roadmap

## MVP 0.1 — EP001 UX pilot

- web dashboard
- episode storyboard
- shot inspector
- asset library
- generation queue
- review queue
- seed data + JSON export

## MVP 0.2 — Persistence

- PostgreSQL
- object storage
- auth + roles
- upload original assets
- generated video versions
- comments + approval history
- immutable locks

## MVP 0.3 — Scale to 80 episodes

- import remaining episode breakdowns
- batch scene / shot creation
- filters and search
- dependency / affected-shot view when an asset changes

## MVP 0.4 — AI operator tools

- downloadable ZIP package
- BytePlus adapter if API access is available
- prompt templates / presets
- previous-last-frame + target-first-frame management

## MVP 0.5 — QC + editorial integrations

- visual compare mode
- face / environment consistency checks
- FFmpeg proxy generation
- EDL / FCPXML export
- production analytics and audit trail
